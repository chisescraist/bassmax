TECH HOUSE BASS LAB - PROYECTO FUENTE VST3 (WINDOWS)

IMPORTANTE: Este ZIP NO contiene un VST3 compilado ni probado en Ableton.
El proyecto es un instrumento VST3 con sintetizador de bajo interno y salida MIDI adicional.
Ableton Live puede no permitir dirigir la salida MIDI de un VST3 hacia Serum 2.
El bajo interno permite escuchar los patrones sin depender de esa función.

PARA COMPILAR EN WINDOWS:
1. Instalar Visual Studio 2022 con Desktop development with C++ y CMake.
2. Instalar Git y CMake si no vienen con Visual Studio.
3. Abrir terminal en esta carpeta.
4. Ejecutar: cmake -S . -B build -G "Visual Studio 17 2022" -A x64
5. Ejecutar: cmake --build build --config Release --target TechHouseBassLab_VST3
6. Copiar la carpeta build/TechHouseBassLab_artefacts/Release/VST3/Tech House Bass Lab.vst3
   a C:/Program Files/Common Files/VST3/
7. Reiniciar Live y buscar Tech House Bass Lab en Plug-ins > VST3.

ALTERNATIVA: subir este proyecto a un repositorio GitHub y ejecutar
Actions > Build Windows VST3 > Run workflow. Descargar el artifact del build.

USO:
- Insertar como instrumento VST3 en una pista MIDI.
- Iniciar el transporte de Live. RUN=1, Root=29 (F1), Groove=0, Gain=0.3.
- Cambiar Seed para crear otro patrón reproducible.
- Groove: 0 Rolling, 1 Offbeat, 2 Syncopated, 3 Minimal.
- La interfaz es la interfaz genérica de parámetros, no un diseño gráfico personalizado.
- La salida MIDI hacia Serum 2 NO está garantizada en Ableton Live; usar bajo interno.
