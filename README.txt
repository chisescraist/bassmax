TECH HOUSE BASS LAB V1 - prototype for Ableton Live 12 Suite / Max for Live / Serum 2

1. Unzip the entire folder; keep .maxpat and .js together.
2. In Ableton create a MIDI track and load a Max MIDI Effect device (for example, a blank Max MIDI Effect). Click Edit to open Max.
3. In Max open Tech_House_Bass_Lab.maxpat, then save the patch AS a Max for Live MIDI device (.amxd) using File > Save As while editing the MIDI effect, or copy the patch contents into the opened device and save.
4. Put the saved MIDI device before Serum 2 on the same MIDI track. Start Ableton transport, then click RUN in the device patch.
5. Controls: GROOVE 0 Rolling, 1 Offbeat, 2 Syncopated, 3 Minimal; DENSITY 0-100; ROOT MIDI 29 = F1 (octave labels vary); GENERATE changes pattern; RESET starts at step 1.
6. Stop RUN before switching projects. Use a short monophonic Serum 2 bass preset.

IMPORTANT: This is an editable Max patch prototype, not a tested native .amxd or .adg. The JS file must remain next to the patch when editing. This environment cannot run Ableton or validate the device inside Live.
